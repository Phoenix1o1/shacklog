Second copy of backups

{{ app_name }} backs up the database once a day and before every import. It can also copy each backup to another folder: a OneDrive folder on a PC, or a NAS share mounted on the server. Only finished backup files go there, never the live database, so a syncing cloud folder can't damage it.
