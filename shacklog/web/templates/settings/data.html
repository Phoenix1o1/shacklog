Bundle: everything in one file

A bundle is a zip holding the database and every library file. Use it for a computer that never reaches the hub, or as a complete archive on a USB stick.

{{ csrf() }}

Import a bundle or database

Pick a bundle (.zip) made by “Export bundle”, or a shacklog.sqlite3 database file from another instance. Its records are merged into this one:

  • records missing here are added;
  • when both have the same record, the newer version wins and the other is kept under Conflicts;
  • nothing here is deleted, and importing the same file twice changes nothing.

A backup of this database is made first. A file from a newer {{ app_name }} is refused until you update this one.
