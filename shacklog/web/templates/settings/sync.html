How sync works

Each instance keeps its own database. A sync sends this computer's changes to the hub, then fetches everything the hub has that this computer lacks, library files included.

When the same record was edited in two places, the newer edit wins and the other one is kept under Conflicts, where you can restore it. Deleted records travel as deletions and can be restored from the trash.

Settings, passwords and tokens never leave the computer they belong to.

No network between two machines? Use a bundle instead.
